# PRD — 잇고톡 MVP

- 버전: 0.1 (2026-10-05)
- 근거 자료: 앱 개발 논의점(2026.10.5), 연산 프로그램 덧셈(합 10 이하), 교재 체계, 프로그램 체계 예시, 서비스 기획서

## 1. 목표
학원 3~5곳 파일럿에서 다음 한 바퀴가 실제로 돌아가는 것을 검증한다.

> 학생이 덧셈·뺄셈 단계를 시간 기준으로 통과 → 교사가 기록을 보고 첨삭·출력 → 학부모가 2주 리포트를 받는다.

## 2. 사용자 역할
| 역할 코드 | 설명 |
|---|---|
| `student` | 학원 원생. 지역·학교를 골라 가입, 기관 초대 코드로 소속 |
| `teacher` | 학원 강사/공부방 선생님. 기관(organization)에 소속 |
| `org_admin` | 원장. 교사 권한 + 기관 설정, 교사 승인 |
| `parent` | 학부모. 로그인 없이 리포트 링크로 열람 (MVP) |
| `admin` | 본사 운영자. 지역·학교·기관·콘텐츠 관리 |

## 3. 사용자 스토리와 수용 기준

### 회원·기관
**ST-01 학생 가입** — 학생은 지역 → 학교 → 학년을 선택하고 기관 초대 코드를 입력해 가입한다.
- [ ] 지역·학교 목록은 관리자가 등록한 것만 보인다.
- [ ] 초대 코드가 틀리면 가입되지 않는다.
- [ ] 학부모 휴대폰 번호와 법정대리인 동의 체크가 필수다.
- [ ] 학생 화면 어디에도 실명이 노출되지 않고 이니셜로 표시된다.

**ST-02 교사 가입·기관 연결** — 교사는 기관 코드로 가입하고 원장 승인 후 활성화된다.
- [ ] 미승인 교사는 학생 정보를 볼 수 없다.

**ST-03 관리자 지역·학교 관리** — 관리자는 지역과 학교를 추가·수정·비활성화한다.

### 학습
**ST-10 입회 진단 테스트** — 신규 학생은 첫 로그인 시 진단 테스트를 본다.
- [ ] 스킬 순서대로 대표 세트를 출제하고, 처음 통과하지 못한 스킬을 시작 스킬로 지정한다.
- [ ] 결과는 교사 화면과 PDF로 확인할 수 있다.

**ST-11 연산 훈련 루프** — 학생은 현재 스킬의 문항 세트를 연습 3회 후 테스트한다. (규칙: `learning-engine.md`)
- [ ] 연습 모드는 정답 여부를 즉시 피드백한다.
- [ ] 연습 3회 완료 전에는 테스트 버튼이 비활성이다.
- [ ] 테스트는 같은 세트 문항을 랜덤 순서로 출제한다.
- [ ] 통과 시 다음 세트/스킬이 열리고 축하 화면을 보여준다.
- [ ] 테스트 3회 연속 미통과 시 직전 스킬 복습 세트가 배정되고 교사에게 알림이 간다.

**ST-12 문제 입력 UI** — 숫자 패드(0~9, 지우기)로 답을 입력한다. □ 위치(결과 칸 또는 두 번째 항)를 지원한다.
- [ ] 태블릿 가로 화면에서 한 손으로 입력 가능하다.
- [ ] 화면에는 남은 시간 대신 경과 "기록"을 보여준다. (속도 압박 완화)
- [ ] 문항 아래에 스킬의 힌트 문장을 보여준다. 예) "더하기 2는 두 칸 간 수. 2→→4"

**ST-13 혼자 놀기 (AI 시합)** — 학생은 AI 상대와 같은 문항으로 속도 시합을 한다.
- [ ] AI 속도는 학생의 최근 테스트 기록보다 약 10% 빠르게 설정된다.
- [ ] 시합 결과도 Attempt(mode=`race_ai`)로 저장되지만 진도 판정에는 쓰지 않는다.

### 교사
**ST-20 학생 목록·상세** — 교사는 자기 기관 학생의 현재 스킬, 최근 기록, 정체 여부(3회 연속 실패)를 본다.
- [ ] 다른 기관 학생은 API 수준에서 조회되지 않는다(RLS).

**ST-21 첨삭·출력** — 교사는 Attempt/리포트에 코멘트를 남기고 PDF로 출력한다.

### 학부모
**ST-30 2주 리포트** — 매 14일마다 학생별 리포트가 생성되고 학부모 번호로 링크가 발송된다.
- [ ] 문장 예: "+3 교환법칙: 9/27 10문항 18초 → 10/4 10문항 11초, 다음 단계 진행"
- [ ] 링크는 토큰 기반이며 30일 후 만료된다.
- [ ] MVP는 발송을 이메일/콘솔 모의 발송으로 대체해도 된다(카카오 알림톡 연동은 2차).

### 관리자
**ST-40 콘텐츠 업로드** — 관리자는 `skills.csv`, `items_*.csv` 형식 파일을 업로드해 스킬·문항을 갱신한다.
- [ ] 정답 칸이 실제 계산 결과와 다르면 업로드를 거부하고 행 번호를 보여준다.

## 4. 비기능 요구사항
- 태블릿(1024×768 이상) 가로 우선, 모바일 세로에서도 깨지지 않을 것
- 문항 전환 100ms 이내 (세트 전체를 미리 로드)
- 시간 측정은 `performance.now()` 사용, 서버 기록과 교차 검증
- 개인정보: 만 14세 미만 법정대리인 동의, 최소 수집, 교사 열람 범위 제한

## 5. MVP 범위 밖
실시간 대전, 친구·부모 초대 시합, 읽고 말하는 수학(개념 트랙), 결제, 네이티브 앱, 수학 외 과목, 숫자판·화살 도입 연출(2차).
