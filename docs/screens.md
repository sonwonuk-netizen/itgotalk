# 화면 명세 (MVP)

태블릿 가로(1024×768) 기준. 라우트는 Next.js App Router 경로.

## 학생 `/s/*`
| 라우트 | 화면 | 주요 요소 |
|---|---|---|
| `/login` | 로그인 | 아이디/비번, 학부모 동의 미완료 시 안내 |
| `/signup/student` | 학생 가입 | 지역 → 학교 → 학년 → 초대코드 → 학부모 번호·동의 |
| `/s/diagnostic` | 입회 진단 | 스킬별 대표 세트 연속 출제, 진행 바, 결과 화면 |
| `/s/home` | 학습 메인 | 이니셜 아바타, 현재 스킬 카드, "연습하기"(n/3), "테스트"(잠금 표시), "AI랑 시합" |
| `/s/play/[setId]?mode=practice\|test\|race_ai` | 문항 풀이 | 아래 상세 |
| `/s/result/[attemptId]` | 결과 | 정답 수, 기록(초), 통과/재도전, 다음 단계 버튼 |
| `/s/records` | 내 기록 | 스킬 지도(통과/진행/잠김), 최고 기록 |

### `/s/play` 문항 화면 레이아웃
```
┌──────────────────────────────────────────────┐
│ 이니셜  +2 교환법칙 · 세트 9   기록 00:07.4    │
├───────────────────────┬──────────────────────┤
│                       │   7   8   9          │
│     3 + 2 = [  ]      │   4   5   6          │
│                       │   1   2   3          │
│  (문항 4 / 7)          │   ⌫   0   확인       │
├───────────────────────┴──────────────────────┤
│ 힌트: 3+2=2+3                                  │
└──────────────────────────────────────────────┘
```
- 연습: 오답이면 빨간 표시 후 같은 문항 재입력, 정답 공개 없음(2회 오답 시 공개).
- 테스트: 피드백 없이 다음 문항, 끝나면 결과 화면.
- `race_ai`: 상단에 AI 진행 바(롤러) 추가.

## 교사 `/t/*`
| 라우트 | 화면 | 주요 요소 |
|---|---|---|
| `/signup/teacher` | 교사 가입 | 기관 코드, 승인 대기 안내 |
| `/t/students` | 학생 목록 | 이니셜·학년·학교, 현재 스킬, 최근 기록, 정체 경고 배지 |
| `/t/students/[id]` | 학생 상세 | 스킬 진행표, Attempt 목록(날짜·모드·정답·초), 오답 문항, 코멘트 |
| `/t/students/[id]/print` | 출력 | 진단 결과 또는 기간 기록 PDF |
| `/t/alerts` | 알림 | 3회 연속 실패 학생 |
| `/t/org` (원장) | 기관 설정 | 초대코드 재발급, 교사 승인 |

## 학부모 `/r/[token]`
- 로그인 없음. 리포트 문장 목록, 기간, 학원명, 교사 코멘트.

## 관리자 `/admin/*`
| 라우트 | 화면 |
|---|---|
| `/admin/regions` | 지역·학교 CRUD |
| `/admin/orgs` | 기관 생성·초대코드 |
| `/admin/content` | CSV 업로드(검증 결과 표시), 스킬/세트/문항 조회 |
| `/admin/reports` | 리포트 생성·발송 로그 |

## 디자인 톤
- 아이용 화면: 큰 숫자(문항 64px 이상), 둥근 버튼, 밝은 배경, 실패 문구는 "한 번 더!" 같은 긍정형.
- 교사·관리자 화면: 일반 대시보드 스타일, 표 중심.
