# Claude Code 단계별 개발 프롬프트

이 키트 폴더를 새 저장소 루트에 복사한 뒤, Claude Code에서 아래 프롬프트를 **순서대로 하나씩** 붙여 넣으세요.
각 단계가 끝나면 결과를 직접 확인하고 커밋한 뒤 다음 단계로 넘어갑니다.

---

### 0단계 — 맥락 파악
```
CLAUDE.md와 docs/ 폴더의 모든 문서, content/의 CSV, db/schema.sql을 읽어줘.
코드는 아직 쓰지 말고, 이해한 내용을 요약하고 PRD의 미결 사항(Q1~Q5) 외에
구현 전에 확인이 필요한 점이 있으면 질문해줘.
```

### 1단계 — 프로젝트 뼈대
```
CLAUDE.md의 기술 스택으로 Next.js 프로젝트를 초기화해줘.
TypeScript strict, Tailwind, Vitest, Playwright, ESLint 설정까지 하고
docs/screens.md의 라우트 구조대로 빈 페이지를 만들어줘.
pnpm dev, pnpm test, pnpm lint, pnpm typecheck가 모두 통과해야 해.
```

### 2단계 — 학습 엔진 (가장 중요)
```
docs/learning-engine.md를 그대로 구현해줘. 위치는 src/lib/engine/.
DB나 React에 의존하지 않는 순수 함수로 만들고,
9장의 테스트 케이스 T1~T12를 Vitest로 먼저 작성한 뒤(실패 확인) 구현해서 통과시켜줘.
```

### 3단계 — DB와 시드
```
db/schema.sql로 Supabase 마이그레이션을 만들고,
content/skills.csv와 content/items_addition_sum10.csv를 읽어 넣는 pnpm db:seed 스크립트를 작성해줘.
시드할 때 모든 문항의 answer를 a, op, b, blank로 다시 계산해 다르면 행 번호와 함께 실패하게 해줘.
schema.sql 하단의 RLS 규칙을 정책 SQL로 작성하고, 다른 기관 교사가 학생을 조회할 수 없는지 테스트해줘.
```

### 4단계 — 가입·로그인
```
PRD의 ST-01, ST-02, ST-03을 구현해줘. Supabase Auth 사용.
학생 화면에는 이니셜만 보이게 하고, 학부모 동의 없이는 가입이 완료되지 않게 해줘.
```

### 5단계 — 문항 풀이 화면과 훈련 루프
```
PRD ST-11, ST-12와 docs/screens.md의 /s/home, /s/play, /s/result를 구현해줘.
시간 측정은 performance.now로 하고, 시작/종료를 서버에도 기록해서
2단계 엔진 함수로 통과 여부를 서버에서 판정해줘.
Playwright로 "연습 3회 → 테스트 통과 → 다음 세트 열림" 흐름 E2E를 작성해줘.
```

### 6단계 — 진단 테스트와 AI 시합
```
PRD ST-10(입회 진단)과 ST-13(혼자 놀기 AI 시합)을 구현해줘.
AI 시합 결과는 진도 판정에 쓰지 않는다는 점을 지켜줘.
```

### 7단계 — 교사 화면
```
PRD ST-20, ST-21과 /t/* 화면을 구현해줘.
학생 상세의 오답 문항 목록, 코멘트, PDF 출력(/t/students/[id]/print)까지.
```

### 8단계 — 학부모 리포트
```
PRD ST-30을 구현해줘. learning-engine.md 8장의 문장 규칙을 쓰고,
발송은 지금은 콘솔 로그로 대체하되 나중에 카카오 알림톡으로 바꾸기 쉽게 인터페이스로 분리해줘.
```

### 9단계 — 관리자
```
PRD ST-40과 /admin/* 화면을 구현해줘. CSV 업로드 검증 로직은 3단계 시드 스크립트와 같은 함수를 재사용해줘.
```

### 10단계 — 점검
```
PRD의 모든 수용 기준 체크박스를 하나씩 확인해서 충족 여부 표를 만들어줘.
미충족 항목은 이유와 수정 계획을 적고, 접근성(큰 글씨, 터치 영역 48px 이상)도 점검해줘.
```

---

## 팁

- 미결 사항(Q1~Q5)이 정해지면 PRD.md를 먼저 고친 뒤 "PRD가 바뀌었어. 변경점 반영해줘"라고 하세요.
- 2단계 엔진 테스트가 깨지는 변경은 받아들이지 마세요. 진도 판정의 신뢰가 서비스의 핵심입니다.
